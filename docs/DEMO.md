# Демо на Technopark EXPO (14 декабря 2026)

## Перед выставкой (на MSI)

```powershell
.venv\Scripts\python.exe -m aldau.train_baseline        # модель models/baseline.joblib (вариант both)
.venv\Scripts\python.exe -m pytest -q                   # всё зелёное
```

## Основное демо — Telegram-бот

```powershell
.venv\Scripts\python.exe -m aldau.bot                   # учитель в серой зоне 🟡, до 10 запросов в день
.venv\Scripts\python.exe -m aldau.bot --no-teacher      # без запросов к Gemini вообще
```

- Работает через long polling: нужен только интернет, сервер и открытый порт не нужны.
- Логи — `data/bot.db` (замаскированный текст объявления, риски, отзыв; данных о пользователях нет).
- Если учитель недоступен (лимит, 503, нет интернета) или не ответил за 20 с, бот отвечает
  локальной моделью с пометкой «углублённая проверка недоступна». Бот не падает.

## Запасное демо без Telegram и без интернета

```powershell
.venv\Scripts\python.exe -m aldau.check --file docs/demo_ads.txt    # заготовленные объявления
.venv\Scripts\python.exe -m aldau.check                             # вставить своё, закончить строкой ---
.venv\Scripts\python.exe -m aldau.web                               # страница http://127.0.0.1:8000
```

По умолчанию оба режима работают офлайн (только локальная модель и регулярки). Флаг `--teacher`
включает учителя для 🟡: не больше 1 запроса на объявление и в пределах дневного лимита.

## Сценарий (черновик)

1. Проблема: мошеннические объявления на OLX/Kolesa/Krisha, схемы с предоплатой.
2. Явная схема → 🔴, причины и совет.
3. Обычное объявление → 🟢.
4. Сомнительное → 🟡, «⏳ углублённая проверка», ответ обновляется.
5. Казахский текст.
6. Ограничения: учебный прототип, 74 обучающих объявления, нет настоящих scam в обучении.
   Модель путает честную бронь с мошенничеством, поэтому ответ — вероятность, а не вердикт.
7. Кнопки «верно / неверно» и `/stats`.

11.12 — заморозка кода, 12–13.12 — репетиция, в том числе офлайн.
