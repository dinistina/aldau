# Как собирать и размечать данные (Фаза 1)

Данные собираешь ты сам, руками. Код только помогает сохранять и размечать.
Краулеров нет и не будет: массовый сбор с OLX / Kolesa / Krisha запрещён правилами проекта.

## Что нужно получить

| Что | Сколько | Где лежит |
|---|---|---|
| Все собранные объявления | 200–300 | `data/raw/ads.jsonl` |
| Gold-набор — твоя ручная разметка | 100 из них | `data/gold/gold.jsonl` |

Папка `data/` не попадает в git. На второй ноутбук её нужно переносить вручную (флешка / облако).

## Подготовка (один раз на каждом ноутбуке)

```
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

Все команды ниже запускай из корня проекта (`F:\aldau`).

## Шаг 1. Добавить объявление

```
.venv\Scripts\python.exe -m aldau.collect add
```

Программа по очереди спросит:

1. **Источник** — `olx`, `kolesa` или `krisha`. Для примера из новостей укажи площадку, на которую
   он похож по стилю.
2. **Категория** — пиши одинаково каждый раз (см. список ниже), иначе «телефоны» и «смартфоны»
   станут двумя разными категориями.
3. **Заголовок**.
4. **Текст** — вставь текст, потом на отдельной строке напиши `END` и нажми Enter.
5. **Цена в тенге** — только число, можно с пробелами. Пусто, если цены нет.
6. **Город**.
7. **Метка** — `s` (scam) или `l` (legit), только если знаешь точно (например, пример взят из
   новости о мошенничестве). В остальных случаях просто Enter.

После этого программа покажет текст **после маскировки** и спросит, сохранять ли.

Если текст длинный или с казахскими буквами вставляется криво, сохрани его в файл в кодировке
UTF-8 и передай так:

```
.venv\Scripts\python.exe -m aldau.collect add --text-file ad.txt
```

### Быстрый способ: пакетный импорт

Вместо добавления по одному можно собрать много объявлений в один текстовый файл
(например `data/inbox.txt`, кодировка UTF-8) и добавить все сразу.

Формат: объявления разделяются строкой `---`. У каждого сначала шапка, потом заголовок, потом текст:

```
источник | категория | цена | город | метка | origin | пометка (необязательно)
Заголовок объявления
Текст объявления, сколько угодно строк...
---
olx | телефоны | 220000 | Алматы | legit | real
iPhone 13 128 гб
Продам айфон, состояние хорошее.
---
```

Поля шапки:

| Поле | Значения |
|---|---|
| источник | `olx`, `kolesa`, `krisha` |
| категория | любая, но пиши одинаково (см. список ниже) |
| цена | число в тенге, можно с пробелами; можно оставить пустым |
| город | можно оставить пустым |
| метка | `scam`, `legit`, `unknown`; пусто = `unknown` |
| origin | `real` — настоящий текст (с площадки или со скриншота жертвы); `case_based` — переписано по новости / жалобе / памятке; пусто = `real` |
| пометка | 7-е поле, необязательно: откуда именно текст, например `tg-канал, скриншот жертвы`, `отзыв в Instagram`. Без имён и ников |

**Цена в шапке — это цена, указанная на сайте** (в поле «цена» объявления), даже если в тексте
написано другое число. Для скриншотов без поля цены — цена из текста.

Сначала проверка без сохранения, потом сам импорт:

```
.venv\Scripts\python.exe -m aldau.collect import data/inbox.txt --dry-run
.venv\Scripts\python.exe -m aldau.collect import data/inbox.txt
```

В конце команда показывает, сколько добавлено (по меткам, языку, категориям), в каких объявлениях
были замаскированы личные данные, какие пропущены как дубликаты и какие не прошли проверку —
с номером объявления и номером строки в файле. Объявление с ошибкой не останавливает импорт:
исправь его в файле и запусти команду ещё раз, уже добавленные будут пропущены как дубликаты.

Ещё импорт предупреждает, если **цена в шапке расходится с ценой в тексте** больше чем на 10 %
(например, в шапке 30 000, а в тексте «отдам за 25.000»). Это только предупреждение — объявление
всё равно добавляется. Проверка эвристическая: суммы рядом со словами «депозит», «задаток»,
«покупал за», «новый стоит» она пропускает, но иногда может ошибиться в обе стороны.

**Как исправить уже добавленное объявление.** Поправь шапку в inbox-файле (цену, метку, категорию,
город, origin) и запусти `import` ещё раз. Если текст объявления не менялся, сохранённая запись
обновится, и импорт покажет её в разделе «Обновлены». Если поменять сам текст, это будет новое
объявление — старое тогда нужно удалить из `data/raw/ads.jsonl` руками.

Проверить расхождения цен во всех уже сохранённых объявлениях:

```
.venv\Scripts\python.exe -m aldau.collect check-prices
```

Если расхождение нормальное (например, в тексте цена после торга), добавь id объявления
(он в квадратных скобках в выводе `check-prices`) в файл `data/price_ok.txt`, по одному на строку,
комментарий после `#`. Такие объявления больше не показываются ни в `check-prices`, ни в `import`.

**Посуточная аренда — отдельная категория** (`посуточная аренда`): цена за сутки и цена за месяц
несравнимы, а признак «цена относительно рынка» считается по медиане внутри категории.

### Обязательно: проверь глазами перед сохранением

Телефоны, почта, ссылки и @ники маскируются надёжно. **Имена — нет.** Программа знает только
частые имена и фразы вроде «меня зовут …». Если в тексте осталось имя, фамилия, точный адрес,
номер карты или номер машины — ответь `n`, убери это из текста руками и добавь объявление заново.

Ещё мошенники часто пишут номер словами или с буквами вместо цифр («восемь семь ноль один…»,
«8 7О1…»), чтобы обойти фильтры площадки. Такой номер программа не замаскирует. Замени его в тексте
на `[PHONE]` вручную — сам факт, что номер был спрятан, при этом сохранится в тексте как признак.

### Рекомендуемые категории

`телефоны`, `электроника`, `авто`, `запчасти`, `аренда квартир`, `посуточная аренда`, `продажа квартир`, `работа`, `услуги`,
`животные`, `детские товары`, `одежда`, `мебель`, `другое`

## Шаг 2. Что и откуда собирать

**Обычные объявления (примерно 60–70 %)** — открывай площадки как обычный пользователь и копируй
текст вручную. Бери разные категории, города и цены, а не 100 айфонов из Алматы.

**Подозрительные и мошеннические (примерно 30–40 %)**:
- **настоящие тексты мошенников** со скриншотов жертв (Telegram-каналы, Instagram, отзывы) —
  копируй текст как есть, `origin = real`, в 7-м поле пометка, откуда он. Скриншоты жертв часто
  содержат имена и номера карт — проверяй особенно внимательно;
- новости о заблокированных объявлениях и задержанных мошенниках;
- памятки по безопасности от OLX, Kolesa, Krisha, полиции и прокуратуры;
- жалобы в соцсетях и на форумах («осторожно, развод»);
- объявления на площадках, которые выглядят подозрительно тебе самому.

Примеры из новостей и жалоб **переписывай своими словами, сохраняя схему**: что предлагают,
какая цена, чего требуют от покупателя. Личные данные не копируй вообще.

**Типичные схемы, которые стоит покрыть** (хотя бы по несколько примеров каждой):
- предоплата / задаток / «бронь» до просмотра (особенно аренда квартир);
- цена сильно ниже рынка + срочность («уезжаю», «только сегодня»);
- увод в мессенджер («пишите только в WhatsApp / Telegram»);
- «безопасная сделка» или «доставка» по ссылке, где просят данные карты;
- товар «из-за границы» / «с таможни» с оплатой вперёд;
- работа с оплатой «за обучение», «за оформление», «за форму»;
- животные «бесплатно, оплатите только доставку».

**Казахский язык.** Постарайся, чтобы хотя бы 20–30 % объявлений были на казахском: модель должна
работать на обоих языках. Чего не хватит — доберём синтетикой в Фазе 4, но в gold-наборе должны
быть настоящие казахские объявления.

**Трудные случаи важнее простых.** Честное объявление с низкой ценой («срочно продаю, переезд»)
и аккуратно написанное мошенническое — именно на них проверяется модель. Собирай такие специально.

**Не дай стилю выдать метку.** Если все мошеннические примеры переписаны аккуратным языком, а все
честные — живые, с опечатками, модель научится отличать стиль, а не обман. Поэтому нужны:
- аккуратные честные объявления: дилеры, агентства, магазины;
- честные объявления с законной бронью или депозитом: гостиницы, легальная посуточная аренда;
- законные запчасти (Kolesa), чтобы категория «запчасти» не была только мошеннической;
- настоящие (не переписанные) тексты мошенников.

**Не дай категории выдать метку.** Если в какой-то категории почти все объявления scam (или
почти все legit), модель может решать по категории, не читая текст. Смотри колонку «% scam»
в `stats` и добирай то, чего не хватает.

## Шаг 3. Посмотреть, сколько собрано

```
.venv\Scripts\python.exe -m aldau.collect stats
```

Покажет таблицы «категория × метка», «origin × метка» и «язык × метка» с долей scam в каждой
строке. Пример:

```
  категория         scam legit unkn. всего  % scam
  запчасти             5     0     0     5    100%   <- перекос: категория выдаёт метку
  одежда               0    12     0    12      0%   <- нет ни одного scam
```

Строка со 100 % или 0 % scam — сигнал, чего добрать.

## Шаг 4. Разметить gold-набор

Когда собрано хотя бы 200 объявлений:

```
.venv\Scripts\python.exe -m aldau.collect gold
```

Программа показывает объявления по одному в случайном порядке. Отвечай:

- `s` — scam (мошенничество);
- `l` — legit (обычное объявление);
- `st` или `lt` — то же, плюс пометка **«по тексту не распознать»**: метка верная, но из
  текста объявления её не понять. Пример: настоящее мошенничество, где само объявление
  выглядит обычным, а обман случился потом в переписке. В отчётах recall показывается
  с такими объявлениями и без них;
- `n` — пропустить (объявление не попадёт в gold и останется для обучения);
- `q` — выйти. Прогресс сохраняется после каждого ответа, можно продолжить позже.

Пропущенные (`n`) записываются в `data/gold/skipped.txt` и больше не предлагаются; их число
видно в `stats`. Вернуться к ним: `collect gold --include-skipped`. Непонятный ответ
(опечатка) программа переспросит, а не посчитает пропуском.

**Добавить в gold только новые объявления** (например, настоящие тексты мошенников со
скриншотов): сложи их в отдельный inbox, импортируй и размечай только его:

```
.venv\Scripts\python.exe -m aldau.collect import data/inbox3.txt
.venv\Scripts\python.exe -m aldau.collect gold --only-inbox data/inbox3.txt
```

С `--only-inbox` ограничение в 100 объявлений не действует.

После 100 размеченных объявлений программа остановится сама.

### Правила разметки

- **Решай по тексту и цене**, как решал бы покупатель. Не подглядывай, откуда ты взял объявление.
- **scam** — есть явная схема обмана: требуют деньги вперёд, уводят на стороннюю ссылку, условия
  нереалистичны.
- **legit** — обычное объявление, даже если написано неграмотно или цена немного ниже рынка.
- **Не уверен — жми `n`.** В эталоне должны быть только те ответы, в которых ты уверен. Сомнительный
  эталон делает бессмысленными все метрики.
- **Следи за балансом.** В gold должно быть не меньше 30 объявлений scam, иначе precision и recall
  будут считаться на слишком маленьком числе примеров. Проверяй через `stats`.
- **`case_based` в gold разрешены** (решение от 2026-11-17), пока настоящих scam мало. Все метрики
  потом считаются отдельно для `real` и `case_based`. Сгенерированные (`synthetic`) объявления
  программа в gold не предлагает никогда.
- **Размечай за 2–3 подхода, а не за один.** Уставший разметчик ошибается.

### Почему gold нельзя трогать после разметки

Gold — это экзамен для модели. Обучение его никогда не видит: объявления из gold будут исключены
из train по `id`. Если после плохого результата менять метки в gold «чтобы сошлось», экзамен
перестаёт что-либо измерять. Исправлять можно только явную ошибку (нажал не ту клавишу) — открой
`data/gold/gold.jsonl` в редакторе и поправь поле `label` в нужной строке.

## Шаг 5. Проверить gold, исправить и заморозить

Сравнить метки в gold с метками, которые были в шапке inbox при импорте:

```
.venv\Scripts\python.exe -m aldau.gold diff
```

Исправить метку (каждое изменение с причиной пишется в `data/gold_changes.jsonl`):

```
.venv\Scripts\python.exe -m aldau.gold change <id> --label scam --t --reason "почему"
```

`--t` — пометка «по тексту не распознать». Напоминание о смысле: **метка — правда об объявлении**
(было ли это мошенничество), а `t` — «из текста этого не видно». Мошенничество с обычным на вид
текстом — это `scam --t`, а не `legit --t`.

Когда всё перечитано — заморозить:

```
.venv\Scripts\python.exe -m aldau.gold freeze
.venv\Scripts\python.exe -m aldau.gold check
```

После заморозки `gold` и `gold change` отказываются работать, а `check` (и код обучения в Фазе 5)
сверяет отпечаток SHA-256 файла: даже случайная правка будет замечена.

## Шаг 6. Второй разметчик и Cohen's kappa

Второй человек размечает 30 случайных объявлений из gold, не видя твоих меток:

```
.venv\Scripts\python.exe -m aldau.agreement sample
.venv\Scripts\python.exe -m aldau.agreement label
.venv\Scripts\python.exe -m aldau.agreement kappa
```

Он видит только то же, что видел ты: источник, категорию, город, цену, заголовок и текст.
Ответы те же (`s`, `l`, `st`, `lt`, `n`, `q`), прогресс сохраняется. Его метки лежат отдельно —
`data/gold/second_annotator.jsonl` — и gold не меняют.
