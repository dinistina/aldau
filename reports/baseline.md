# Baseline-ученик (Фаза 5) — прототип

TF-IDF по буквенным кусочкам слов + признаки Фазы 2 → LogisticRegression.
Обучен на **метках владельца из импорта** (не на метках учителя); gold в обучении не участвовал. **Это маленький прототип**, цифры ниже — не оценка готовой системы.

## Данные

- обучение: 74 объявлений {'legit': 57, 'scam': 17}; origin/метка: {'real/legit': 57, 'case_based/scam': 17}
- убрано из обучения почти-копий gold (совпадение слов ≥ 80 %): 0
- проверка (gold): 120 объявлений, scam 37, из них настоящих (real) 9

**Главное ограничение:** в обучении все scam — переписанные кейсы (case_based), все legit — настоящие объявления. Модель может научиться отличать стиль пересказа, а не схему обмана. Честная проверка — срез `real` в gold: этих scam модель не видела ни в каком виде.

Кросс-валидация на train выбрала: **text**, C = 10.0, порог 0.40 (gold в этом выборе не участвовал).

**Для демо сохранён другой вариант — both** (C = 10.0, порог 0.73; C и порог — тоже по CV на train). Его выбрал владелец **после просмотра результатов на gold**, поэтому цифры этого варианта на gold оптимистичны: gold использован для выбора. Честный результат (выбор только по CV) — вариант **text**, он ниже. Главная причина расхождения: в обучении нет настоящих scam, и текстовая модель выучила стиль пересказа, а не схему обмана. Чистая проверка демо-варианта — на новом тестовом наборе живых объявлений (план после EXPO).
