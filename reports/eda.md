## 3. Цена относительно рынка

`price_ratio` = цена объявления / медианная цена в той же категории (и городе, если там хотя бы 3 объявления). 0.3 = на 70 % дешевле обычного.

| price_ratio | scam | legit |
|---|---|---|
| < 0.25 (в 4+ раза дешевле) | 3 | 5 |
| 0.25–0.5 | 4 | 15 |
| 0.5–0.8 | 6 | 16 |
| 0.8–1.25 (обычная цена) | 19 | 28 |
| 1.25–2 | 7 | 16 |
| > 2 | 6 | 15 |

- scam: цена известна у 45, медиана price_ratio 1.00, дешевле половины рынка — 16 %
- legit: цена известна у 95, медиана price_ratio 1.00, дешевле половины рынка — 21 %

## 4. Предсказывает ли одно поле метку само по себе?

Для каждого поля — простейший «классификатор», который видит только это поле (для категориальных полей: доля scam среди объявлений с тем же значением, посчитанная на других фолдах, 5-кратная стратифицированная кросс-валидация). ROC-AUC: 0.5 — поле бесполезно, 1.0 — поле одно угадывает метку.

Для полей, не связанных со смыслом объявления (категория, origin, источник, город), высокий ROC-AUC — это **перекос данных**: модель может выучить его вместо схемы обмана.

| поле | ROC-AUC | насколько выдаёт метку |
|---|---|---|
| категория | 0.78 | сильно |
| источник (olx / kolesa / krisha) | 0.59 | слабо / почти случайно |
| язык | 0.51 | слабо / почти случайно |
| город | 0.72 | заметно |
| origin (real / case_based) | 1.00 | очень сильно — почти угадывает метку |
| число сигналов | 0.98 | очень сильно — почти угадывает метку |
| price_ratio (дешевле = подозрительнее) | 0.48 | слабо / почти случайно |

## Оговорки

- Данных мало (около 140 размеченных объявлений): каждая доля — это несколько штук, разница в 5–10 процентных пунктов может быть случайной.
- Все scam-объявления сейчас `case_based` (переписаны вручную), все legit — `real`. Поэтому различия в сигналах частично отражают то, *как писались* кейсы: в пересказе схемы слово «предоплата» обычно есть явно. Проверка на настоящих мошеннических объявлениях — после того как они будут собраны.
- Медианы цен посчитаны по всем объявлениям, включая само объявление. Для EDA это допустимо; при обучении (Фаза 5) медианы считаются только по train.
